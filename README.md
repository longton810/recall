# Recall

A separate Recall app based on the latest Odontogram project. It retains the existing charting, findings, suggested treatment, Note, copying, and Undo behavior. Its browser tab and page title are Recall, and its autosave key is separate from Odontogram.

## Run locally

Keep index.html, style.css, and script.js together and open index.html in a browser.

## Publish

Create a GitHub repository named recall under longton810. Extract the ZIP and upload these files directly into the repository root. Enable GitHub Pages for that branch and root folder. The intended address is https://longton810.github.io/recall/.
